# Channel Finder TV design system

## Reviewed usability contract (2026-10-13)
Preserve the compact TV appearance, safe margins, existing palette, typography and focus primitives. Prioritise predictable remote focus and meaningful content over extra decoration.
- Library search/category/sort controls lead Down into the first discovery poster or Continue Watching when present. Every focused poster reveals its whole card, including title/progress and outline. Focus restoration after details preserves selection; changing sort starts at the top. Sorting offers provider order, title A–Z and newest known year; unknown years remain last. Year and quality are secondary metadata when supplied or unambiguously encoded as suffixes, never invented.
- Home channel cards prioritise channel name and programme, with up to two lines each, rather than repetitive category prefixes. A fixed contextual footer describes OK and long OK for the focused item. Removing a favorite or pin moves to the nearest surviving card in that row, or its recovery action/France when empty. Pinned cards use minimum heights and grow with enlarged text.
- Guide opens on the requested channel with Toutes selected. Its header identifies the originating selection. Programme filtering preserves the active channel even when its schedule is empty or unavailable, and rows do not disappear underneath remote focus. Missing programme data never implies failed playback.
- Chercher partout clears country and quality restrictions as well as lane/category scope, keeping the search text. The viewer sees an unambiguous all-channel scope.
- Setup form owns vertical scrolling in its bounded pane and accommodates the IME, 130% text and inline validation errors. The HTTP warning remains in the form; focus reveals fields and the connection action. Setup identity uses Canapé.

## 1. Atmosphere & identity
A compact French-language TV library, legible from the sofa. Navy tonal layers keep live video prominent; a light focused surface or white artwork outline identifies the remote's current target. Preserve the existing lane colors and country flags, which identify the viewer's shortcuts.

## 2. Color
The authoritative Kotlin tokens live in `Theme.kt`, object `Palette`: Ink #0A0F18, InkTop #111A29, Surface1 #151E2C, Surface2 #1D2939, Outline #2F3D52, OnSurface / FocusFill #F2F5FA, Muted #BAC5D4, Faint #94A2B6, Accent #8AB8FF, AccentDeep #22395C, OnFocus #0A0F18, AccentOnLight #1C4F9C, Gold #FFCB57, GoldOnLight #9A6A00, Live #FF4D5E, Warning #FFCB80, WarningSurface #2E2414, Error #FF9C9C, ErrorSurface #331A1E, LogoPlate #223047.
Lane gradient pairs: France #27448F / #162550; Português #1C6B45 / #0F3527; Sports #8A4A16 / #45240D; Événements #6A2A6E / #2E1533. White and black are reserved for video overlays. Status always has text or a glyph.
`ErrorOnLight` #A52332 keeps unavailable-channel badges readable on the light focused row.

## 3. Typography
Android's system sans serif, using `Type`: Display 28/34 sp bold; Headline 22/28 semibold; Title 19/24 semibold; TitleSmall 17/22 semibold; Body 16/22; Label 15/19 semibold; Caption 14/18; Eyebrow 13/16 bold with 1.2 sp tracking; Badge 12/15 bold with 0.5 sp tracking. Running text stays at least 14 sp. Support 130% system font scale; metadata truncates with ellipsis, important labels wrap or grow.

## 4. Spacing & layout
Compact density: Gutter 12 dp, Row 16 dp, ListGap/ListPadding 4 dp, ChannelArtwork 54 dp. Home channel strips use five columns, while the four destination cards keep their existing column count. Lane cards use 88 dp minimum height with an 8 dp internal spacer; channel cards use a 108 dp minimum and grow for programme titles or enlarged text. Browser rows retain the 56 dp minimum with 4 dp vertical padding; guide rows use 6 dp vertical padding and 4 dp list gaps. Category rows use 46 dp minimum and 8 dp vertical padding. Safe margins and typography remain unchanged.
`Spacing.Side` 58 dp, `Top` 28 dp. Drawer rail 80 dp and content inset 38 dp. Home columns share the actual available width after drawer and side margins; lane cards never scroll horizontally. Channel strips scroll independently with 10 dp vertical focus clearance. Browser list rows retain a 56 dp minimum; chips retain 32/38 dp minima, growing for scaled text. Screen-level footer gap 10 dp. Preview actions and metadata can wrap independently. List and category regions own their vertical scroll; Home owns vertical scroll and its channel strips own horizontal scroll.

## 5. Components
- `FocusSurface`: clickable row/button/chip, dark resting fill, light focused fill/dark content, subdued pressed fill, dim disabled state. Scale varies by density. Long-press semantics exist only for a real secondary action.
- `CardSurface`: artwork or lane card with white 3 dp focus outline, 1 dp resting outline, 1.05 scale. Home channels show logo or initials, name, quality and current programme; favorites add a star. Each Home row stretches cards to its tallest content, without fixed global heights.
- `TvButton`: 42 dp minimum, icon plus action verb, primary filled Accent, secondary outlined. Preview actions use the compact variant: 12 dp horizontal padding, 18 dp icons, 6 dp icon-label gap and 8 dp between buttons. The preview favorite stays icon-only on focus with an accessibility action label, keeping the three standard actions on one line at normal text size. Enlarged text and additional recent-channel actions may wrap. `TvChip`: compact/sized variants; selected state includes a check and accessibility selection state.
- `TvTextField`: 48 dp minimum, scoped placeholder and accessibility label. Focus alone never opens the IME; OK edits; Back closes it and ends editing.
- `Badge`, `ChannelLogo`, `EventTag`: noninteractive metadata. A provider EPG ID is not a working programme guide and does not warrant a GUIDE badge.
- `HintBar`: nonfocusable remote key plus action label, contextual to browsing or playback.
- `EmptyState`, `Callout`, `NoticeHost`: empty/error explanations beside the affected content, with an available recovery action when applicable.
- `AppDrawer`: collapsed icon rail; focus expands it, OK navigates, Back on a drawer root opens the drawer. Focus restores when returning from playback.

## 6. Motion & interaction
Menu destination changes replace the page without a crossfade, avoiding overlapping focusable screens. The incoming destination restores its own focus; the drawer only hands focus into the content group when reselecting the current destination. Libraries focus search while loading or empty, and restore the selected poster when results arrive. Detail/playback transitions retain the existing fades.
Preserve existing native transitions: 150 ms surface scale; 160/120 ms screen crossfade; preview overlay 400 ms out / 150 ms in. Preview settles for 650 ms before opening a muted stream. Zapping settles for 250 ms before switching; the banner follows each press immediately. Player banner hides after five seconds. Android animation duration settings govern Compose animation. No new decorative animation. OK opens/plays; long OK toggles favorite or pin; Right reaches preview actions; Left returns to the selected list row; Right/Down reach the next preview action, and Down from the final action returns to the row.

Live lane sorting, country counts and search, and movie/series filtering run off the UI thread. Search fields update immediately; pending results show Recherche… and never expose results from an older query as the current selection. Initial focus restoration waits for completed results and does not interrupt typing. Empty-result recovery checks also run in the background.

## 7. Depth & surface
Mixed tonal depth and focus elevation. Rows use 14 dp corners, cards/preview 16 dp, badges 6 dp, buttons/chips circular. Buttons use a light focus fill and scale without glow or shadow; other existing surfaces retain their Accent glow and light focus outlines. Selection uses a tonal fill and check/preview glyph; focus must remain distinct from selection.

## 8. Accessibility constraints & existing limitations
All essential actions must be reachable with D-pad only. Preserve 58/28 dp TV safe margins, visible focus, 4.5:1 normal text / 3:1 large text contrast, password masking, and the HTTP transport warning. No account credentials on shared screens. Icon-only actions require accessibility names; selected chips expose selection state.
Existing limitations: provider logos/availability vary; event timezone is undocumented; physical-TV performance is unmeasured; programme coverage depends on the saved provider. Country flags remain existing navigational cues rather than introducing a new icon system. Setup with saved real credentials is not screenshotted in QA.

## Films and series extension

Continue Watching removal opens a shared confirmation dialog naming the title. Annuler receives initial focus, Retirer carries a trash icon, and Back cancels. The original held OK press is consumed in both the app root and dialog window so its release cannot trigger another action. Movie details uses the same confirmation.

Provider category changes keep Continue Watching visible for the current library, independent of the title's category. A changed category clears title search, selected poster/hero and scroll position, then restores focus at the top after its results arrive. Reselecting the current category without an active search preserves the browsing position. Back from details/player preserves the current category's selection and scroll. Title search continues to hide Continue Watching while active.
Dense VOD library: artwork leads, Movies and Series omit the discovery banner, and Continue Watching precedes discovery. Poster cards retain their size on focus (scale 1.0) with a white outline; native grid focus scrolling reveals the selected card without a second delayed clearance request. Cinematic heroes remain on detail screens. Real provider art and metadata only; no invented recommendations, ratings or trailers. Live TV retains its existing system.
`Cinema` tokens: Background #101014, Panel #1B1B22, Accent #E5484D, CardRadius 8 dp, HeroHeight 128 dp (144 at enlarged text), PosterRatio 2/3, LargePosterRatio 0.95, GridGap 16 dp, six columns at normal text and five at 130%, ResumeWidth 200 dp. Existing Type/Palette text and 58/28 dp safe margins apply. At enlarged text the artwork fits inside a shorter frame to keep titles/progress visible; otherwise artwork crops to its frame. Provider failures use a readable fallback. Hero artwork fades into the dark background, never behind unprotected text. Poster focus uses the CardSurface white outline with scale 1.0 around artwork plus title/progress; native grid scrolling reveals the whole focused card. Progress bars use Accent on a muted track and a text position; completed items carry Vu.
Fixed header holds destination, scoped search, category picker and Trier. Sorting offers provider order, title A–Z and descending known year, with unknown years last. Each library retains its choice while open; changing it preserves query/category and resets position. Conservative explicit year/quality suffixes become secondary metadata; original titles remain searchable. A LazyVerticalGrid fills the remaining vertical region: Continue Watching horizontal reel, section header and poster grid. Down from header enters the first content card; a grid-scoped native bring-into-view policy reveals complete focused cards with 8 dp clearance. The category overlay owns a searchable vertical list; Back dismisses it. Poster OK opens movie details or series episodes. Returning restores the selected poster and grid scroll. Search never steals IME focus. Continue Watching OK resumes directly; long OK removes an entry and restores focus. Detail pages offer Reprendre / Regarder, Recommencer and series Épisode suivant where applicable. Episodes use landscape cards in a three-column grid (two at enlarged text), with season chips, watch progress and readable titles. No automatic live preview.
Watch history persists metadata, position, duration and parent series per hashed account, capped at 100 entries. Save every five seconds, on pause/seek/background and on exit. Unknown duration never implies completion; actual end or 95% watched marks completion and removes the entry from Continue Watching. Films and episodes resume independently; a series contributes its most recently watched episode if it is unfinished. Resume is automatic unless Recommencer is chosen. Series playback loads its episode queue on a cache miss, including a cold-start resume; a failed queue load offers retry after playback ends. Loading uses poster-shaped skeletons; errors and empty states explain the affected content with retry/filter recovery. Physical-TV readability remains unverified.

## TV guide extension
Home's recent and favorite channel cards also show current titles when available. Browsing and Home omit loading/error/missing-programme placeholders; only the guide retains explicit states. Cards grow with the extra Caption line.
Current-programme summaries also appear in regular browsing lists (France, Português, Sports, Favorites, Recents and search). Event feeds keep their existing event title/status instead. The same settled, bounded row loader and one-line Caption apply.
Category channel rows reuse the guide's current-programme summary with Caption, one line and ellipsis, below existing badges. Fetch only composed rows after a 650 ms settling delay, with two background requests at most and cancellation on exit. The guide has two compact chips: Programme en cours and Toutes (default). Programme filtering retains unknown rows and the active channel; completed non-active rows without a current interval or with a request error are excluded. Filter availability is frozen while focus is in the channel pane and updates after leaving it, so asynchronous checks never remove rows during channel navigation. Missing schedule data never replaces the requested channel. Manual refresh and the 15-minute schedule check revalidate availability. The header names the originating scope and channel count.
Channel rows show the current programme below channel/version metadata, using Caption with one line and ellipsis. The channel pane is 240 dp to keep titles readable while retaining list density. Rows retain their 56 dp minimum and grow with content. Only composed rows load schedules, after 650 ms, with at most two background requests; the selected channel reuses the main schedule. Current titles use interval checks every 30 seconds; schedules refresh every 15 minutes or with Actualiser. Loading, missing current programmes and request errors have explicit French labels.
The guide uses a full-screen three-pane list-detail shell: channels (240 dp), programme list (remaining width), description/actions (260 dp), separated by Gutter. Each pane owns its vertical scroll; header and remote hints stay fixed. Existing Type/Palette/FocusSurface/TvButton tokens apply. Programme rows grow from 56 dp; titles allow two lines. At 130% text, details scroll independently and actions remain reachable. Initial focus is the selected channel; Right reaches its current/next programme, Left returns to that channel, Right from a programme reaches the direct-play action. Programme focus updates details without starting playback. OK on a programme or the direct action plays the live channel; future/past schedules never imply catch-up. Empty schedules, loading, and provider errors are distinct with refresh/retry. Provider epoch timestamps display in the TV's local timezone; schedule data loads on demand with a bounded 15-minute memory cache, not one request per catalog channel.

The navigation drawer owns a vertical scroll so Guide TV, Categories and Settings remain individually reachable at enlarged text sizes. During playback, Left opens the guide; Back restores playback. Description focus has a white outline and an explicit ↑↓ reading hint. Channel rows include version metadata to distinguish duplicate feeds.
