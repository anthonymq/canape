# Canapé brand assets

- `app-icon.png`: original user-selected sofa/C icon with coral play triangle, supplied as `Image ChatGPT 13 oct. 2026, 17_12_30.png`. The master is unchanged, 1254 × 1254 with transparent outer corners. Android `mipmap-*/ic_launcher.png` assets are resized to 80, 120, 160, 240 and 320 pixels; `AppMark` uses the same launcher resource without a tint.
- `canape-wordmark.png`: approved horizontal logo with the blue sofa/C emblem supplying the initial C and white `anapé` lettering. Used in the README masthead.

The Android TV banner combines the selected app icon with the existing readable Canapé lettering on midnight navy. Its source is `app/src/main/res/drawable/canape_banner.xml`, with text in `canape_wordmark.xml`.

Exploration files in the local `design/` directory are not required to build the app. These committed master assets and the Android resources are the production sources.
